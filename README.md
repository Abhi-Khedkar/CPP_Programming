# CPP_Programming
C++ Programming - Logic Building Batch

📝 Description

This repository tracks my progressive journey in C++ Programming through the Logic Building batch. It contains daily classwork practice programs and structured assignment solutions. The codebase evolves from foundational programming concepts (loops, conditions, basic logic) to Object-Oriented Programming (OOP) principles, classes, pointers, memory management, and advanced problem-solving.

Author: Abhishek Mahesh Khedkar

🚀 How to Compile and Run

All programs are written in standard C++ and can be compiled and executed using the GCC compiler (g++) via the terminal or command prompt.

Open your terminal and navigate to the specific folder (either a Classwork day or a specific Assignment):

cd Classwork/Day_01
# OR
cd Assignments/Assignment_1


Compile the C++ program using g++ (replace filename.cpp with the actual file name):

g++ filename.cpp -o outputname


Run the generated executable:

On Windows:

.\outputname.exe


On Linux / Mac:

./outputname
